# gRPC-сервер и клиент

В каталоге находится аналог пары из `plain-text` на gRPC. Один вызов `Counter.Exchange` — двунаправленный стрим: клиент непрерывно отправляет `Request{id}`, одновременно читает `Response{id, data}`, а сервер увеличивает общий атомарный `uint64` счётчик для каждого запроса. Первое значение `data` — 1.

Запуск из каталога `gRPC`:

```sh
go run ./cmd/server -listen :9001
go run ./cmd/client 127.0.0.1 9001
```

Вторую команду выполняйте в другом терминале. Для нескольких параллельных gRPC-стримов внутри одного TCP-соединения используйте `-streams`, например:

```sh
go run ./cmd/client -streams 8 127.0.0.1 9001
```

Клиент создаёт один `grpc.ClientConn` и запускает указанное число двунаправленных стримов поверх него. При нормальной работе все они используют одно TCP-соединение. После обрыва транспортное соединение может быть создано заново. Клиент раз в секунду печатает `sent/s`, `responses/s` и общее число полученных ответов. `responses/s` показывает завершённые запросы; `SendMsg` может вернуться раньше, чем сервер обработает сообщение. После обрыва клиент создаёт новый стрим, сохраняя атомарный счётчик ID. Остановка — Ctrl+C.

Сервер читает запросы и пишет ответы одновременно, через ограниченную очередь ID на каждый стрим. `RecvMsg` принимает запрос в повторно используемый объект vtprotobuf. Клиент так же повторно использует объект ответа. Для отправки создаётся отдельный объект сообщения: gRPC допускает его отложенное использование после `SendMsg`. Кодек vtprotobuf зарегистрирован для обеих программ.

Файлы Go для Protobuf и gRPC уже сгенерированы. Для повторной генерации нужен `protoc`; версии Go-генераторов закреплены в `go.mod`:

```sh
bash generate.sh
```

Проверка:

```sh
go test -race ./...
```

RPS измеряется по `responses/s`: это число ответов, полученных за секунду. Локальный прогон с одним установленным TCP-соединением (`ss`), примерно 7 секунд на вариант; в таблице среднее последних пяти секунд:

| Стримов в одном соединении | Ответов/с |
| ---: | ---: |
| 1 | 1 288 000 |
| 2 | 1 099 000 |
| 4 | 915 000 |
| 8 | 882 000 |
| 16 | 836 000 |
| 32 | 749 000 |

В этом прогоне максимум дал один стрим, поэтому он остаётся значением по умолчанию. Скорость на другой машине может отличаться.
